### About Me

- I build LLM agents and RAG systems, and I like evaluating them honestly: golden sets, regression gates, and written-down limits.
- I am moving toward AI security: how agents fail under untrusted input and which defenses actually hold. Notes live in [llm-security-writeups](https://github.com/Lolavine777/llm-security-writeups).
- My undergraduate thesis models Active Directory as a weighted graph so defenders can see the cheapest paths to critical assets and re-check them after a fix.
- Trained in the VinUni AI20k program (cohort 3, Track 3): hands-on labs from RAG and multi-agent systems to evaluation, guardrails, and alignment.
- How to reach me: [LinkedIn](https://www.linkedin.com/in/nguyen-dang-long-a9aa752ab/)
